# Frontend - 10N-AI 💻

Interfaz de usuario interactiva y HUD futurista desarrollado con **React + Tailwind CSS**.

### Responsabilidades:
* Renderizado interactivo de partículas faciales (Selector de personalidades: Core D10S / Core CR7).
* Captura de audio del micrófono y envío de comandos de voz.
* Captura de fotogramas de la cámara web para reconocimiento de expresiones.
* Visualización gráfica de resultados de las predicciones de Machine Learning.
