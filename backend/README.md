# Backend - 10N-AI 🚀

Módulo de servicios backend y API REST desarrollado con **FastAPI**.

### Responsabilidades:
* Servir los endpoints de inferencia para los 10 modelos de Machine Learning.
* Procesar las solicitudes de reconocimiento de emociones y visión por computadora.
* Gestionar el procesamiento de comandos de voz (Speech-to-Text).
